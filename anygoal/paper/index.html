AnyGoal

A compositional generalization suite for world model research

Documentation Code

Overview

AnyGoal brings together manipulation and navigation tasks to study how world models generalize across goals and task compositions. The moving gallery above shows the first episode from each environment.

Tasks

Explore twelve environments spanning PushT, Cube, peg manipulation, and TwoRoom navigation, including recombined task variants.

Evaluation

Use the benchmark's datasets and evaluation tools to compare model behavior across distinct goals.
